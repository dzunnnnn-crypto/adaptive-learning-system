# Формат учебного материала

Публичный пример использует строгую schemaVersion 7 с явным `videoSource.materialMode: "embedded-only"`.

- `videoSource`: YouTube videoId, исходная ссылка, автор, длительность и упорядоченные интервалы глав.
- `units`: самостоятельные названия и короткие учебные связки; ровно три вопроса с вариантами А/Б/В и объяснениями.
- `sourceArtifacts`: ссылки на официальный плеер для каждой главы.
- `coverage`: связь учебных глав с временными интервалами.
- `courses/catalog.json`: видимая библиотека. `courses/roadmaps.json`: необязательные сборники, в этом примере пустой список.

В режиме embedded-only схема запрещает встраивать `transcript` и `subtitleAsset`. Обычные локальные пакеты без этого режима по-прежнему обязаны содержать расшифровку и проверенные субтитры. Новый режим не ослабляет проверки старого формата.

`source.status: "verified"` означает проверку источника и структуры, а не разрешение распространять весь исходный материал. Права проверяются отдельно.

Чтобы подготовить следующий собственный пакет, выберите разрешённый источник, задайте смысловые границы, подготовьте вопросы, зарегистрируйте его в каталоге и запустите `npm run validate`. Не добавляйте полные тексты, субтитры, изображения или PDF без подтверждённых прав.

Шаблоны content/templates/ намеренно имеют needs-review и не являются готовыми курсами. Для собственного первого embed-only пакета ориентируйтесь на courses/chatgpt-images-practice/course.json. Интерфейс произвольный импорт по URL пока не выполняет.
