# Безопасность

## Модель использования

Текущая версия предназначена для локального запуска одним пользователем. Сервер слушает только `127.0.0.1`. Это не готовая многопользовательская платформа для публикации через обратный прокси.

- При обычном `npm start` AI выключен. Файлы `.env` не загружаются, адаптеры моделей не создаются. Ключи из окружения не используются, если не установлен `ENABLE_AI=1`.
- Проверяются Host и Origin изменяющих запросов; запросы с чужого сайта отклоняются. Эта проверка дополняет loopback-привязку, но не защищает от вредоносного ПО на том же компьютере.
- Статически раздаётся только `public/`. Прогресс, код сервера, `.env` и runtime-каталог не раздаются как файлы.
- Запросы проверяются строгими Zod-схемами; размер JSON ограничен 32 КБ.
- Доступ к материалам идёт через записи каталога. Проверки локальных вложений ограничивают пути и сверяют контрольные суммы. Публичный пример не содержит вложений или субтитров.
- Ответы, навигация и позиция видео сохраняются в `.local/runtime/`, который исключён из Git. Разрешения на каталог остаются ответственностью владельца компьютера.
- YouTube получает обычные данные посетителя встроенного плеера. Не используйте чувствительные материалы в публичных учебных пакетах.

## Резерв и восстановление

Остановите процесс и сохраните копию всего каталога `.local/runtime/`. Для восстановления верните целиком этот каталог, включая `courses/`, `app-state.json`, `playlist-state.json` и `initialized.json`.

Если память существующего курса пропала или повреждена, приложение не сбрасывает её автоматически. Восстановите резерв или задайте новый отдельный `DATA_ROOT`, чтобы начать независимый сеанс. При несовпадении версии содержимого с runtime требуется явная миграция или новый каталог; старый прогресс не перезаписывается.

## Дополнительный AI

Для разработки адаптеров можно явно установить `ENABLE_AI=1`. Codex использует окружение и локальную авторизацию владельца, Z.AI требует его ключа. Это отдельные внешние сервисы со своими условиями и возможными расходами. Запуск по умолчанию их не вызывает. Реальные платные запросы в проверку примера не входят.

Для примера видео AI-пояснения не нужны. Не включайте модели при запуске незнакомым посетителям и не открывайте локальный порт в интернет.

## Сообщить о проблеме

Можно создать issue с описанием воспроизведения, но без ключей, личных курсов и истории ответов. Если нужен чувствительный пример, сначала согласуйте закрытый канал с владельцем репозитория.
