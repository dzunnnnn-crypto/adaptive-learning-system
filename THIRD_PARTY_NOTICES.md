# Источники и лицензии

## Код приложения

Код выделен из собственной локальной учебной системы автора. Здесь нет импортированной Git-истории, личной библиотеки, пользовательских ответов или секретов. Код и самостоятельный учебный слой распространяются по MIT, см. LICENSE.

## Видео учебного примера

- Автор: Иван, канал «ИИ на практике».
- Источник: https://www.youtube.com/watch?v=6hT9lEmZzF4
- Использование: официальный встроенный YouTube-плеер с временными интервалами.
- Сам видеоролик, аудиодорожка, полная расшифровка и VTT в репозиторий не включены.
- Публичная доступность и разрешённое встраивание проверены 26.10.2026. Это не подтверждение лицензии CC BY на полный материал. Мы не распространяем видео под MIT.
- Скриншоты демонстрируют интерфейс приложения. Если на них видны элементы плеера, названия или кадры источника, права на эти элементы остаются у соответствующих правообладателей.

Условия YouTube: https://www.youtube.com/static?template=terms
Параметры официального плеера: https://developers.google.com/youtube/player_parameters
Типы лицензий: https://support.google.com/youtube/answer/2797468?hl=ru

## Зависимости

| Пакет | Назначение | Лицензия |
|---|---|---|
| Express | HTTP-сервер | MIT |
| Zod | Проверка данных | MIT |
| @openai/codex-sdk | Дополнительный адаптер модели | Apache-2.0 |
| Vitest | Тестирование | MIT |
| jsdom | DOM в тестах | MIT |
| Supertest | Проверка HTTP API | MIT |

Точные версии закреплены в package-lock.json. Лицензии транзитивных пакетов поставляются вместе с ними при `npm ci`; отсутствие node_modules в Git не отменяет их лицензии.

Шаблоны в content/templates/ и данные test/fixtures/ являются демонстрационными. Они не добавляют другие курсы в пользовательскую библиотеку и не содержат их полных текстов.
